Snow on your desktop and window tops! Christmas spirit directly beamed into you Mac!! Shake a window to knock it off, or push it aside with the cursor. Christmas lights included :)

[![Flocon demo](assets/flocon-demo.gif)](assets/flocon-demo.mp4)

## Install

[Download Flocon.dmg](https://github.com/gbrach/flocon/releases/latest/download/Flocon.dmg), open it, and drag Flocon to Applications. You might need to go into Setting and then Securty to allow the app to run.

Intel and Apple Silicon are supported

## Use

Click the snowflake in the menu bar to change snowfall, wind, accumulation, melting and lights; cozy winter, hot chocolate!

**Behind Windows** keeps falling snow behind your apps while it still settles on window tops. The lights work with or without a notch! Get some Christmas spirit :)

Snow and lights pause when the lid is closed, or during sleep.

## Build

If you want to build it yourself...
```sh
./build.sh
open build/Flocon.app
```
